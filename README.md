MSc Cyber Security dissertation evidence repository for Victor Chukwunenye Ogbuehi.

This repository supports my viva defence for the project:

**Behaviour-Based Ransomware Detection Using Windows Telemetry and Machine Learning**

## Important note

The original project virtual machine was wiped during departmental preparation. This repository is therefore an evidence-based reconstruction package, not a recovered original VM repository.

It contains a compressed evidence package showing how the project was structured, how the lab was created, how behavioural features were extracted, how detectors were evaluated, and how the results were preserved.

## Project summary

The project investigated whether ransomware-like file-locking behaviour can be detected using Windows host telemetry and machine learning.

The controlled lab used:

- Windows virtual machine environment
- Sysmon telemetry validation
- Safe ransomware-like simulator
- Benign file workloads
- Behavioural feature extraction
- CSV dataset construction
- Rule-based detector
- Random Forest classifier
- Simple temporal detector
- HMM-style temporal logic
- Live detector timing evidence
